# AI Study Plan

## Goal

Get hired as a remote LLM / AI engineer by building four measured, public portfolio projects. (Private constraints: `private.md`, not committed.)

## Learner profile

- Senior product engineer. Strong in Next.js / TypeScript, learning Python ML tooling and Rust.
- Hardware: M1 MacBook, 16 GB RAM → 7–8B models at 4-bit run locally.
- Depth I want by default: **explain** (I can explain it without notes). Concepts on the exit test need **apply**.

## Daily run-sheet (IST)

| Time | Block | What happens |
|---|---|---|
| 07:00–08:30 | Learn (1.5h) | Reading or video, notes in my own words |
| 08:45–10:45 | Build (2h) | Code toward the week's deliverable; commit before stopping |
| 10:45–11:15 | Post + Log (0.5h) | One post (any format — `/study-coach share`); fill the day's Log section |
| 18:00–19:30 | Rust (1.5h) | The day's Rust line |
| 21:00–22:00 | Optional | Watch list only. Never replaces a block above |

Sundays are light: one 3-hour block for the write-up and scorecard, plus Rust catch-up only if behind. No new material.

## Rules

1. Never shift the calendar. A missed day's Build moves to Sunday; its Learn is dropped unless the Build needs it.
2. Time boxes are hard. When a block's time is up, commit and move on; leftovers go to Sunday.
3. Items marked stretch are the first to drop when behind.
4. New books, courses or videos go to `ideas/parking-lot.md` or the optional evening slot, never into a block.
5. Each task must feed this week's deliverable. Two missed days in a row triggers a scope cut, not extra hours.
6. Day 30 is judged against the exit test, not hours logged.
